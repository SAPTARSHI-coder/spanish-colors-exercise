# Spanish Colors — CSS Selector Exercise

A focused CSS exercise that styles a pre-built HTML page teaching Spanish color vocabulary. The HTML structure is fixed; all styling is applied purely through CSS using ID selectors, element selectors, and property targeting.

## Overview

The page displays five Spanish color names — Rojo, Azul, Anaranjado, Verde, and Amarillo — each rendered in its corresponding color, accompanied by a color swatch image. The exercise reinforces CSS specificity rules by requiring ID-based selectors for individual heading colors.

## Tech Stack

| Technology | Role |
|---|---|
| HTML5 | Pre-defined page structure |
| CSS3 | All styling via selector targeting |

## Project Structure

```
spanish-colors-exercise/
├── index.html          — Page structure (not modified)
├── style.css           — Exercise solution styles
├── assets/images/      — Color swatch image files
└── solution/           — Reference implementation
```

## Getting Started

Open `index.html` directly in any browser. No internet connection or build step required.

## Key Concepts

- `color` property for text coloring
- `font-weight` normalization using element selectors
- `width` and `height` on `<img>` elements via CSS
- **ID selector** specificity (`#red`, `#blue`, etc.)
- CSS cascade and specificity: understanding why ID selectors override element selectors
